TO-DO LIST APPLICATION

DESCRIPTION:
This is a basic console-based To-Do List application written in Python. It allows users to manage their tasks by viewing, adding, marking as complete, and removing tasks from a list.

FEATURES
- View all tasks with their completion status.
- Add new tasks to the list.
- Mark existing tasks as complete.
- Remove tasks from the list.
- Simple, interactive menu-driven interface.
  
HOW TO USE
1. Run the Python script todo_list.py.
2. A menu will appear with several options.
3. Enter the number corresponding to the action you want to perform (e.g., 1 to view tasks, 2 to add a task).
4. Follow the prompts to interact with your To-Do List.
